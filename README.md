# Круг на троих 3D — онлайн-гонки без сервера

Гонки на 1–3 игрока. Игроки соединяются напрямую (WebRTC через PeerJS), хост даёт друзьям ссылку. Игровой сервер не нужен.

## Запуск
Модели (GLB) браузер грузит через fetch, поэтому открывайте проект через локальный сервер, а не двойным кликом:

    python3 -m http.server 8000      # затем откройте http://localhost:8000

Без папки `models/` игра работает: тогда рисуются встроенные процедурные машины и деревья.
Нужен интернет (three.js грузится с CDN).

## Установка и запуск (npm)
    npm install      # ставит three и peerjs и копирует нужные файлы в libs/ (скрипт scripts/copy-libs.js)
    npm start        # локальный сервер: http://localhost:8000
    npm run gen-tracks   # перегенерировать 30 случайных трасс (js/tracks-gen.js); можно указать seed
index.html сначала берёт библиотеки из `libs/`, а если их нет, то подтягивает с CDN. Для GitHub Pages закоммитьте папку `libs/` (`node_modules/` не нужна).

## Трассы, биомы и турнир
В игре 34 трассы: 4 ручные и 30 сгенерированных (кольца и спринты) в 12 биомах: лес, дюны, снега, осень, тропики, вулкан, каньон, болото, кристаллы, ночной лес, тундра, саванна. Биомы описаны в `BIOMES` (config.js), у каждого свои земля, небо, горы и декорации.
Турнир: в меню укажите, сколько трасс (2…34), и нажмите «Старт турнира». Трассы выбираются случайно без повторов, за места начисляется 10/6/4 очка, между заездами показывается таблица, в конце победитель. Запускает хост (или игра в одиночку), гости видят то же самое. Если гонщик не финишировал в течение 45 с после первого, заезд считается завершённым.

## Структура
    index.html          полноэкранная игра + меню в модальном окне (кнопка «Меню» или Esc)
    editor.html         редактор трасс: зум колесом, сдвиг, спринт, отправка в игру
    css/style.css       интерфейс
    js/config.js        константы, 10 машин, трассы, настроение сцены, настройки сети (NET, ICE)
    js/render.js        рендерер, небо, свет, тени, текстуры, частицы
    js/track.js         сплайн трассы (равномерный шаг), асфальт, отбойники, арки, горы, деревья
    js/cars.js          загрузка GLB, подгонка, запасная процедурная машина
    js/state.js         состояние игроков, старт гонки, расстановка на решётке
    js/tracks-gen.js    30 сгенерированных трасс (создаётся scripts/gen-tracks.js)
    js/tournament.js    турнир: выбор трасс, очки, таблица между заездами
    scripts/            copy-libs.js (postinstall), serve.js (npm start), gen-tracks.js
    package.json        three 0.128.0 и peerjs 1.5.4
    js/custom.js        «Своя трасса»: приём из редактора (localStorage) или вставкой JSON
    js/ui.js            модальное меню, Esc, полный экран
    js/net.js           сеть: PeerJS, подключение по ссылке
    js/physics.js       физика машины, нитро, столкновения, отбойник
    js/main.js          игровой цикл, камера, HUD, миникарта
    models/             сюда кладутся GLB-модели (MODELS.md)

## Трассы любого размера и спринт
В `js/config.js` у трассы `pts` — контрольные точки в любых координатах (в том числе отрицательных), без ограничения размера.
- `open:true` — спринт: трасса не замкнута, гонка от стартовой арки до финишной (один проезд).
- `scl:N` — свой множитель карты (по умолчанию `SC=3`: координаты умножаются на 3).
Земля, горы, декорации, миникарта и границы подстраиваются под размер сами. Шаг между точками сплайна одинаковый (~10 ед.), поэтому очень длинные и очень короткие сегменты ведут себя одинаково.

## Редактор трасс (editor.html)
Колесо мыши — масштаб (к курсору), ПКМ / СКМ или перетаскивание фона — сдвиг, клик по фону — новая точка (у спринта клик за краем продлевает трассу), двойной клик по точке или Delete — удалить, «Вписать» — показать всю трассу.
«Отправить в игру» кладёт трассу в браузер (localStorage), она появится в списке как «Своя трасса». Для другого устройства: «Копировать JSON» и вставьте в меню игры → «Своя трасса». Для постоянной трассы: «Копировать pts» и вставьте в `TRACKS` в `js/config.js` (для спринта с `open:true`).
Гость получает свою трассу от хоста автоматически.

## GitHub Pages
Загрузите папку в репозиторий, в Settings → Pages выберите ветку и корень. Игра откроется по адресу `https://<user>.github.io/<repo>/`.
Хост жмёт «Я хост», копирует ссылку вида `...?room=race3d-xxxxxx` и отправляет друзьям: страница сама подключит гостя. Хост должен держать вкладку открытой.

## Сеть и Россия
По умолчанию используется PeerJS Cloud и публичный STUN Google, а WebRTC работает по UDP. Если у кого-то не соединяется (в России в 2026 году блокируют и замедляют UDP и часть зарубежной инфраструктуры), нужны свой PeerJS-сервер (`NET.host` в config.js) и TURN с доступом по TCP/TLS (добавьте в `ICE.iceServers`) либо серверная ретрансляция по WebSocket.
